# PROJETO PORTAL DE NOTÍCIAS 💻 

Consiste no desenvolvimento de um website no formato de portal de notícias, utilizando os conceitos de HTML e CSS, com ênfase na propriedade grid.

Updantes: Adicionei Media Query no projeto no intuito de deixa-lô responsivo para dispositivos móveis, além de ter criado um menu lateral somente com HTML e CSS para deixar a página mais acessível para o sistema mobile.
